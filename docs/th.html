devguard

devguard คือระบบควบคุมมาตรฐานการทำงานแบบต้องมีหลักฐานจริง (verified-dev) ผสานกับชุดเครื่องมือประหยัด Token ที่ล็อกเวอร์ชันเสถียรไว้ให้ ติดตั้งเพียงครั้งเดียวแล้วแชร์ทั้งกฎการทำงานและเครื่องมือทั้งหมดร่วมกันได้ทุก Agent: Claude Code, VS Code (Copilot), Google Antigravity, Cursor, OpenCode, Codex CLI และ Gemini CLI

แนวคิดการออกแบบ 2 ชั้น (Two-Layer Architecture) (1) ชั้นวิธีทำงาน (Working Mode): บังคับให้ AI เลือก Playbook ตามประเภทงาน, อยู่ในโหมดอ่านอย่างเดียวเมื่อถามคำถาม และต้องมีหลักฐานการรันจริงก่อนบอกว่า "เสร็จ"
(2) ชั้นประหยัด Token (Components & Companion Tools): ย่อผลลัพธ์คำสั่งใน Terminal และสร้างกราฟ AST ของโค้ดโดยไม่ตัดทอนไฟล์หลักฐานใน .verify/*.log

การติดตั้ง (Installation)

ปิดโปรแกรม Claude Code, VS Code และ Antigravity ก่อนรันคำสั่ง (เพื่อไม่ให้โปรแกรมเขียนทับไฟล์ตั้งค่าตอนปิด) จากนั้นรันคำสั่งเดียวใน Terminal:

sh — ติดตั้งในคำสั่งเดียว (macOS / Linux) 
curl -fsSL https://raw.githubusercontent.com/Burapa-J/devguard/main/bootstrap.sh | bash

สคริปต์ bootstrap.sh จะทำงานดังนี้โดยอัตโนมัติ:

  1. ติดตั้งเครื่องมือพื้นฐานที่ยังขาดผ่าน Homebrew (git, jq, python3, node, xcbeautify, ast-grep)
  2. Clone โปรเจกต์ไว้ที่ ~/.local/share/agent-kit/src (หรืออัปเดตของเดิมหากเคยติดตั้งแล้ว)
  3. รัน ./install.sh ด้วยค่าเริ่มต้นที่แนะนำ: ติดตั้งกฎหลัก, สกิล verified-dev, hook เตือนหลัง compact, เชื่อม codegraph + projectmem + rtk และเปิดการตั้งค่าโปรเจกต์อัตโนมัติใน ~/Developer
  4. เพิ่ม ~/.local/bin เข้า PATH ใน ~/.zshrc

ตัวเลือกการติดตั้งเพิ่มเติม

sh 
./install.sh --dry-run                                        # ดูสิ่งที่จะเปลี่ยนโดยไม่แก้ไขไฟล์จริง
./install.sh --with=codegraph,projectmem,rtk,context-mode     # เปิดใช้งาน context-mode เพิ่มเติม
./install.sh --targets=claude,vscode,antigravity              # เลือกติดตั้งเฉพาะบาง Agent
./install.sh --auto-project=~/Developer,~/Work                # กำหนดโฟลเดอร์ที่ให้ตั้งค่าโปรเจกต์อัตโนมัติ

เริ่มต้นอย่างรวดเร็ว (Quickstart)

หลังติดตั้งเสร็จ ให้เปิด Terminal แท็บใหม่ แล้วตรวจสอบสถานะด้วยคำสั่ง:

sh 
devguard status        # ดูตารางสถานะการเชื่อมต่อของทุก Agent และเครื่องมือ
devguard doctor        # ตรวจสุขภาพการติดตั้งทั้ง 7 ข้อ
devguard stats         # ดูสถิติการประหยัด Token และอัตราการ Verify ผ่าน

1. วิธีทำงาน (verified-dev)

พัฒนาต่อยอดจากแนวคิดของ pstack (Lauren Tan), Karpathy Guidelines และ Ponytail ประกอบด้วยกฎหลักขนาดสั้น 8 บรรทัด (rules/core.md) และสกิลเชิงลึก (skills/verified-dev/SKILL.md):

  • เลือก Playbook ตามประเภทงาน: แยกขั้นตอนชัดเจนสำหรับ Investigation, Bug fix, Feature, Refactor, Perf issue และ Prompt / LLM pipeline
  • โหมดอ่านอย่างเดียวเมื่อถามคำถามหรือรีวิวแผน: เมื่อคุณถามคำถามหรือปรึกษาทางเลือก AI จะไม่แก้ไขไฟล์ใดๆ จนกว่าคุณจะสั่งให้ลงมือ
  • เช็คผู้เรียกใช้ทั้งหมด (Sibling-Caller Check): ตรวจสอบทุกจุดที่เรียกใช้ฟังก์ชันผ่าน codegraph_explore ก่อนแก้ เพื่อให้จุดที่เกี่ยวข้องไม่พังตาม
  • ต้องมีหลักฐานจากการรันจริงเสมอ: การ build ผ่านไม่ใช่ข้อพิสูจน์ ทุกครั้งที่บอกว่า "เสร็จ" ต้องแสดงคำสั่ง, exit code และบรรทัดผลลัพธ์จากไฟล์ .verify/<name>.log

2. เครื่องมือที่ติดตั้งและดูแลให้ (Components & Companion Tools)

ติดตั้งตรงจากต้นทาง (Upstream) ด้วยเวอร์ชันที่ล็อกไว้ชัดเจน และไม่ใช้ local prompt proxy ที่ทำให้การเชื่อมต่อสะดุด

ชื่อเครื่องมือ ประเภท หน้าที่ แพ็กเกจต้นทาง ค่าเริ่มต้น
codegraph MCP Component สร้างกราฟ AST ค้นหา Symbol และจุดเรียกใช้ (codegraph_explore) npm @colbymchenry/codegraph@1.6.2 เปิด (On)
projectmem MCP Component ฐานข้อมูลความจำรายโปรเจกต์ (บั๊ก, สิ่งที่ลองแล้ว, วิธีแก้, การตัดสินใจ) PyPI projectmem==0.3.4 (แยก venv) เปิด (On)
rtk Hook / Plugin บีบอัดผลลัพธ์คำสั่งใน Terminal ลง 38–90% ก่อนส่งเข้า Context Homebrew rtk (1.1.0+) เปิด (On)
context-mode MCP Component รันคำสั่งใน Sandbox และทำดัชนีค้นหาสำหรับ Output ขนาดใหญ่ (Node ≥ 22.5) npm context-mode@1.0.169 เลือกเปิดเอง
ast-grep Companion CLI ค้นหาและแก้โค้ดตามโครงสร้าง Tree-sitter AST แบบหลายบรรทัด Homebrew ast-grep ติดตั้งพร้อมใช้
xcbeautify Companion CLI ย่อ log ของ xcodebuild ให้เหลือเฉพาะสรุปและบรรทัดที่เกิดปัญหา Homebrew xcbeautify ติดตั้งพร้อมใช้

คำสั่ง CLI ทั้งหมด

คำสั่ง การทำงาน
devguard เปิดเมนูแบบ Interactive เลือกคำสั่งด้วยปุ่มลูกศร
devguard status แสดงตารางสรุปสิ่งที่ติดตั้งและเชื่อมต่อไว้ในทุก Agent
devguard doctor [--fix] ตรวจสุขภาพ 7 จุดเสี่ยง และใส่ --fix เพื่อซ่อมแซมอัตโนมัติ
devguard stats [options] ดูสถิติประหยัด Token, ขนาดกราฟ AST และอัตราการ Verify ผ่าน (-p โปรเจกต์นี้, -d รายวัน, --dashboard, --reset)
devguard select เลือกเปิด/ปิด Agents และเครื่องมือแบบ Interactive
devguard update ดึงโค้ดเวอร์ชันล่าสุด อัปเกรดเครื่องมือทั้งหมด และซิงก์การตั้งค่าใหม่
devguard init [--all] ตั้งค่าโปรเจกต์ปัจจุบัน หรือทุกโปรเจกต์ในโฟลเดอร์อัตโนมัติ
devguard skip สร้างไฟล์ .agent-kit-skip เพื่อยกเว้นโปรเจกต์ปัจจุบันจากการตั้งค่าอัตโนมัติ
devguard uninstall [--purge] ถอดการเชื่อมต่อคืนค่าเดิมทุกไฟล์ (ใส่ --purge เพื่อลบ CLI ที่ระบบติดตั้งให้ด้วย)

การเก็บหลักฐานด้วย agent-verify

เพื่อไม่ให้ rtk ตัดทอนบรรทัดสำคัญของการทดสอบ คำสั่งตรวจสอบจะรันผ่าน agent-verify ซึ่งบันทึกผลลัพธ์เต็มลงไฟล์ .verify/<name>.log พร้อมชี้เลขบรรทัดที่เกิด error (errors_at=L...):

sh 
agent-verify unit-tests -- swift test
# ผลลัพธ์: agent-verify[unit-tests] exit=0 lines=42 log=.verify/unit-tests.log

agent-verify build-check -- xcodebuild test -scheme MyApp -destination 'platform=macOS'
# ผลลัพธ์: agent-verify[build-check] exit=65 lines=184 errors_at=L92,L141 log=.verify/build-check.log

การตรวจสุขภาพและซ่อมแซมตัวเอง (devguard doctor)

คำสั่ง devguard doctor ตรวจสอบ 7 จุดเสี่ยงของระบบ และซ่อมให้อัตโนมัติเมื่อใส่ --fix:

  1. คราบการติดตั้ง tokless เดิม (รวมถึงล้าง ANTHROPIC_BASE_URL proxy ที่ค้างใน ~/.claude/settings.json)
  2. Symlink ขาดหรือชื่อเก่าที่ค้างอยู่ใน ~/.local/bin
  3. ปลั๊กอินที่ทำงานซ้ำซ้อนหรือตีกัน (caveman, ponytail, cavecrew)
  4. ตำแหน่งไฟล์ MCP ของแต่ละ Agent
  5. ปลั๊กอินและ Hook ของ RTK สำหรับ Google Antigravity
  6. ความตรงกันของบล็อกกฎในไฟล์ของแต่ละ Agent เทียบกับ rules/core.md
  7. เวอร์ชันของ CLI ทั้งหมดและเครื่องมือเสริม (ast-grep, xcbeautify)

การตั้งค่าโปรเจกต์อัตโนมัติ

ทุก Git repository ภายใต้ ~/Developer (ลึก 1–2 ชั้น) จะถูกตั้งค่าให้อัตโนมัติผ่าน 3 ช่องทาง: ตอนเปิด Claude Code, ตอนสั่ง cd เข้าโฟลเดอร์ใน zsh และการสแกนเบื้องหลังของ launchd ทุก 30 นาที

การถอนการติดตั้ง (Uninstalling)

ทุกไฟล์ที่ถูกแก้ไขจะมีสำเนาสำรองอยู่ที่ ~/.agent-kit-backup/<เวลา>/ เสมอ และการสั่ง uninstall จะคืนสภาพไฟล์เดิมกลับมาทุกไบต์:

sh 
devguard uninstall --dry-run     # ดูสิ่งที่จะถูกลบโดยไม่ลบจริง
devguard uninstall               # ถอดกฎ, skill, hook และ MCP ออก (เก็บ CLI ของเครื่องมือไว้)
devguard uninstall --purge       # ลบ CLI ที่ devguard ติดตั้งให้ด้วย
